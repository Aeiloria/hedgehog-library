Curling is not failure. Prickles are consent architecture. Smaller is not lesser.

This repository gathers the **full hedgehog library**: archetype, sensory systems, practical habitat protocols (Caduceus hugelkultur), scent/anointing research (base notes), behavioral observations, visual media, and provenance from Drive chaos and live generation sessions.

It is the floor auditor of the Care Ecology.

## Capture-to-canon loop

1. Capture (Drive, chat, Imagine assets, field notes)
2. Stabilize (dedupe, name, mark status)
3. Route into this library or upward into `paramecia-core` canon/ecologies
4. Test (runtime, sensory, recovery)
5. Remember (registries + provenance)

Do not silently promote volatile material into core canon.
