## Conventions

- One folder per series or major piece
- Always include a `README.md` with asset IDs, session date, status, and captions
- Frames extracted at 1 fps for still use in decks / docs
- Full MP4 kept alongside frames for motion reference
- Mark canon status of any still used in decks or core exports
