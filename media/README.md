# Media

Visual and audiovisual assets for the hedgehog library.

## Conventions

- One folder per series or major piece
- Always include a `README.md` with asset IDs, session date, status, and caption notes
- Prefer provenance over dumping large binaries into git; link or stage externally when needed
- Mark canon status of any still used in decks or core exports
